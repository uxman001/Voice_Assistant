# Voice_Assistant

A lightweight voice-controlled desktop assistant built with Python. It listens to your microphone, recognizes speech using Google's Speech Recognition API, and responds both verbally and by taking action. Features include speaking the current time, searching Wikipedia for any topic, opening websites like Google and YouTube, and a smart greeting based on the time of day. Simply say stop, exit, or bye to close it. Built using SpeechRecognition, pyttsx3, wikipedia, and pyaudio — no paid API keys required.
